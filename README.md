# Fashion-E-Commerce-Backend (Ndesign)

This is the back-end API for **Ndesign**, a fashion E-commerce APP.

For full project details, setup instructions, and screenshots, see the front-end repository:

**Front-end repo:** [to front-end GitHub repo](https://github.com/ManarALHamad/Fashion-E-Commerce-Frontend)

**Backend**
- Django
- Django REST Framework
- Simple JWT (`rest_framework_simplejwt`) for authentication
- PostgreSQL
